## Shipping workflow

When a feature or change built in this repo is working, merge it to local `main` and push to `origin` right away — don't leave it sitting on a branch or an open PR unless told otherwise. If it went through a PR, merge the PR then pull `main` locally so the local checkout isn't left stale. If it was built directly on a branch or in a worktree, merge that branch into local `main` yourself and push. Do this immediately once the feature is done, without waiting to be asked.
