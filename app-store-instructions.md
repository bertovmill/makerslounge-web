# App Store Connect Setup Instructions

Complete the following tasks on App Store Connect (https://appstoreconnect.apple.com) for the app "Makerslounge".

## 1. Set Copyright
- Navigate to: Apps > Makerslounge > App Information
- Find the "Copyright" field
- Enter: `2026 MakersLounge`
- Click Save

## 2. Set Pricing
- Navigate to: Apps > Makerslounge > Pricing and Availability (left sidebar)
- Set the price to: Free ($0.00)
- Click Save

## 3. Set Content Rights
- Navigate to: Apps > Makerslounge > App Information
- Scroll down to "Content Rights Information"
- Click "Edit" or the relevant button
- Select: "This app does not contain, show, or access third-party content"
- Click Save / Done

## 4. Set Primary Category
- Navigate to: Apps > Makerslounge > App Information
- Find the "Category" section
- Set Primary Category to: Social Networking
- Click Save

## After completing all 4 items:
- Go back to the Distribution > 1.0 Prepare for Submission page
- Click "Add for Review"
