# docs

Reference material for this project that isn't part of the running app —
notes, plans, and source files that inform what gets built but aren't
imported by any page or component.

- `reference/` — raw source files (CSVs, spreadsheets, exports) used to
  populate the app, e.g. the Luma guest list behind the Attendees page.
  Anything with emails, payment info, or other PII stays out of git (see
  `.gitignore`) — drop the file in locally, use it, and it won't be committed.
